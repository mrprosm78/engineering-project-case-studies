# Selected Engineering Case Studies

I build business systems, commerce integrations and workflow automation. These case studies explain selected projects through their problems, design choices and implemented workflows. They are **documentation only**: no application source, customer data or operational configuration is included.

| Case study | Engineering focus |
| --- | --- |
| [Care Operations Platform](care-operations-platform.md) | Recruitment, HR, training, audits, scheduling, attendance and payroll support |
| [Custom Commerce Platform](custom-commerce-platform.md) | WooCommerce storefront, BDM tools, supplier catalogue automation and performance design |
| [Commerce Integration Service](commerce-integration-service.md) | WooCommerce–Shopify product and order exchange with queues, webhooks and reconciliation |
| [Automation Control Platform](automation-control-platform.md) | Project-scoped task control, approvals and worker communication |
| [Document Processing Service](document-processing-service.md) | OCR, review and reliable delivery of documents to a care application |
| [Self-hosted AI and Container Services](self-hosted-ai-services.md) | Containerised OCR, language-model and speech test services |

Start with the first three: each includes a workflow diagram and the engineering decisions behind it. The remaining pages show related automation, document and hosting work.

The care platform also has a [detailed module map](care-operations-module-map.md) covering recruitment, workforce, scheduling, attendance, payroll, quality, documents and operational modules, with current implementation limits.

The case studies describe work supported by private project source and documentation. They distinguish implemented features from prototypes and do not claim unverified usage figures, performance gains or commercial outcomes.
